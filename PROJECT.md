## Interface Contracts

### 1. `source/desktop_core` ↔ `source/host` (C-ABI FFI + JSON-RPC Contract)
- **Exported C Symbols** (`source/host/include/mahayana_app_host.h`): `fabushi_host_create`, `fabushi_host_dispatch`, `fabushi_host_poll_events`, `fabushi_host_cancel`, `fabushi_host_destroy`, `fabushi_host_free_string` (plus legacy aliases routed to the exact same real engine).
- **Envelope Schema**: Request `{"id","method","generation","account_id?","params"}`; Success `{"id","ok":true,"generation","result"}`; Fail-Closed Error `{"id","ok":false,"generation","error":{"code","message","retryable"}}`.
- **Hard Invariant**: Unknown `method` MUST return `ok: false, error.code: "unknown_command"`. Every FFI entrypoint wrapped in `std::panic::catch_unwind`. Zero hardcoded localhost URLs (`DEFAULT_SERVER_URL` default `http://34.46.77.133:8080`). Zero fake sample chats.
- **Required RPC Namespaces**: `auth.*`, `vault.*`, `session.*`, `chats.*`, `folders.*`, `topics.*`, `contacts.*`, `messages.*`, `sync.*`, `outbox.*`, `e2ee.*`, `search.*`, `media.*`, `stories.*`, `stickers.*`, `fabushi.*`, `multi_agent.*`, `magpie.*`, `coding.*`, `mcp.*`, `computers.*`, `remote.*`, `tailnet.*`, `miniapp.*`, `webmcp.*`, `calls.*`, `talk.*`, `wallet.*`, `settings.*`, `proxy.*`, `push.*`, `actions.*`, `generation.*`.

### 2. `source/host` ↔ `mobile/ios/Fabushi/Core` (Swift 6 Strict-Concurrency Contract)
- `FabushiRustHostActor` (`actor`, `Sendable`) & `FabushiCoordinator` (`@MainActor @Observable`) own lifecycle, generation fencing (`accountScopeGeneration`), and domain stores.
- **Zero Mocks & Generation Fencing**: Stale async RPC returns dropped; zero hardcoded credentials, fake Keychain keys, or mock production bridges.
